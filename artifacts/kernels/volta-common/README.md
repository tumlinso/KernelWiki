# Volta shared native support

This bundle contains a compact authored CUDA C++ smoke rather than copied upstream kernel code. It exercises CUDA runtime setup, one opaque WMMA matrix operation and one inline PTX arithmetic instruction. It is not a GEMM implementation or a qualified fragment-layout map. The fixed-input generator and CPU-reference verifier live beside the source in `variants/` and are listed in its provenance record.

The bootstrap design initially proposed `artifacts/kernels/volta-common/full/`. The existing provenance validator admits `asset_mode: derived` only under `artifacts/kernels/*/variants/`; this authored support therefore lives in `variants/`, while source-captured upstream implementations retain the `full/` route. The path adjustment keeps provenance validation unchanged and does not change evidence requirements.

The native source is tested for the narrow environment-smoke scope: the bound controller correctness gate, two follow-up correctness runs, zero-error memcheck with the native PASS record, separate unprofiled timing, and a readable selected NCU report are linked from `benchmark_runs/volta-environment/`. The controller classifies the memcheck wrapper result as partial; that raw result is preserved, and qualification accepts only its zero-error memcheck plus the bound native PASS record. The profile does not qualify performance. The authored source and fixture helpers are recorded in the local `variants/PROVENANCE.yaml`; the environment manifest archives the exact measured ELF before the controller's final gate can rebuild its working path.
