# Scope of this source record

PTX ISA forms and target requirements cited for SM80 asynchronous copies, matrix instructions, and barrier operations. The URL identifies PTX ISA 8.8 in the archived documentation. It is not PTX 9.4, and an available PTX form does not alone prove native eligibility, code generation, numerical behavior beyond that form's contract, or performance.
