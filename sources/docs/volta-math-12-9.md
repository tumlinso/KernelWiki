# Scope of this source record

CUDA integer intrinsics summarized for their public device API signatures and documented semantics, including `__byte_perm`, `__fns`, and signed/unsigned `__dp4a`. PTX target eligibility and lower-level operand behavior are separately referenced to the archived PTX ISA source record. The source's own compiler and target limits remain authoritative. No local execution or performance result is established by this record.
